# 坦克大战 - Tank Battle

基于 HTML5 Canvas 的经典坦克大战游戏，浏览器直接打开即可游玩。

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | `方向键` 或 `WASD` |
| 射击 | `空格` 或 `J` |
| 暂停 | `P` |

## 游戏截图

绿色为玩家坦克，红色为敌方坦克。消灭关卡内所有敌人即可进入下一关。

## 特性

- 10 个难度递增的关卡
- 可破坏的砖墙
- 随机道具掉落（回血、加速、射速提升）
- 支持暂停和重新开始

## 玩法

直接在浏览器中打开 `index.html` 即可开始游戏。点击"开始战斗"按钮进入游戏。
